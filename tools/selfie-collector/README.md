# 방종셀카 수집기 (크롬 확장)

X / 네이버 팬카페에서 방종셀카 이미지를 **로컬 dev 서버**로 수집해 아카이빙하는 보조 도구.
이미지는 로그인된 브라우저 컨텍스트에서 직접 받아오므로 인증이 필요한 소스도 수집된다.

## 사전 준비
1. 로컬 dev 서버 실행: `npm run dev` (http://localhost:3000)
2. 브라우저에서 http://localhost:3000 에 **관리자 계정으로 로그인** (수집 엔드포인트는 관리자 + 로컬 전용)

## 설치 (압축 해제 로드)
1. 크롬 `chrome://extensions` → 우상단 **개발자 모드** 켜기
2. **압축해제된 확장 프로그램 로드** → 이 폴더(`tools/selfie-collector`) 선택

## 사용
1. 스트리머의 X 프로필/타임라인 또는 카페 셀카 글을 연다.
2. 확장 아이콘 클릭 → **현재 페이지 스캔** → 셀카 후보(게시물·이미지·작성일)가 뜬다.
3. 가져올 항목 체크 → **선택 수집**.
4. 이미지가 `selfie-archive/<날짜>/` 에 저장되고 DB(SelfiePost)에 기록된다.
   - 날짜는 게시물 작성일(KST) 기준 자동 분류.

## 수집 후 (분석)
- 수집된 이미지는 `selfie-archive/<날짜>/*.jpg`. Claude가 이 이미지를 읽어 채팅 닉네임을 추출하고
  `npm run` 스크립트 또는 관리자 API로 날짜별 참석자 명단을 기록한다.
  (`node scripts/selfie/record-attendees.mjs --date=YYYY-MM-DD --names="닉1,닉2,..."`)

## 메모
- X 이미지는 `name=orig`(원본 해상도)로 받아온다.
- 자동 스캔은 페이지 구조 변경/가상 스크롤에 취약하다. 후보가 누락되면 게시물을 직접 연 상태에서
  스캔하거나, 스크롤로 더 불러온 뒤 다시 스캔한다.
- 운영(Vercel) 서버에는 파일을 쓸 수 없어 수집은 로컬에서만 동작한다.
