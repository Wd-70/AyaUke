# 사용자 구간 조정 진입점 조사

공통 영상 플레이어의 검은 하단 액션 바를 제거하고, 영상 밖의 화면별 도구에 배치한다.
편집기와 재생 정지/복귀 처리는 `ClipRangeProvider` 하나로 공유한다.

| 화면 / 경로 | 진입점 | 구현 |
| --- | --- | --- |
| 라이브 클립 갤러리 `/clips` → 상세 팝업 | 좋아요·담기·공유 옆 텍스트 액션 | `ClipDetailDialog` |
| 클립 상세·공유 `/clip/[id]` | 정보 아래 액션 줄의 둥근 버튼 | `ClipShareView` |
| 노래책 `/songbook` → 곡 상세 → 라이브클립 | 선택된 클립 행 하단의 보조 도구; 관리자 공식 수정 아이콘과 구분 | `LiveClipManager`, `ClipRow` |
| 전체 플레이어 (전역, `/player`에서도 접근) | 상단 도구의 가위 아이콘 + 텍스트, 모바일은 아이콘 | `MiniPlayer` |
| 재생 대기열 | 각 영상 클립 행의 가위 아이콘, 곡명이 포함된 접근명 | `MiniPlayer` |
| 내/공유 플레이리스트 `/clip-playlist/[shareId]` | 영상 클립별 상세·원본 액션 옆 가위 아이콘 | `ClipPlaylistDetailView` |

## 의도적으로 중복 진입점을 만들지 않는 곳

- 접힌 미니바: 좁은 재생 조작부를 유지한다. 펼치면 상단에서 조정할 수 있다.
- `/player`의 플레이리스트 카드: 특정 클립이 아니므로 조정 버튼 없음. 목록 상세나 전체 플레이어로 연결한다.
- 갤러리 카드·다른 클립 추천 카드: 기존 상세 팝업/상세 링크를 통해 접근한다.
- 녹음 음원·MR: 풀영상의 클립 구간 편집 대상이 아니다.
- `/embed/clip/[id]`: 외부 삽입용 영상 전용 화면으로 유지한다. 편집은 사이트의 클립 상세 페이지에서 한다.
- 관리자 `ClipDetailPanel` 및 생성 검수: 기존 공식 값 편집·추천값 가져오기·검증 흐름을 유지한다.

## 동작 보장

- 목록에서 편집해도 선택곡, 순서, 큐 재생 여부를 바꾸지 않는다.
- 열린 일반 클립 재생 세션들을 일시정지하고, 닫을 때 각 세션의 원래 재생 상태를 복원한다.
- 편집 결과는 동일 클립의 열린 세션들에 적용하고, 기존 위치가 새 구간 밖이면 새 시작점에서 복귀한다.
- 원본 영상 교체 시 이전 영상의 재생 위치를 재사용하지 않는다.
- 비로그인 적용은 현재 앱 세션에서만 유지하며, 계정 변경 시 섞이지 않는다.
- 편집 중 Esc는 편집창만 닫고 뒤의 곡/클립 상세 팝업은 유지한다.
- 모든 새 버튼은 최소 44px 터치 영역, 접근명, 다이얼로그 진입 의미를 제공한다.
- 편집기는 필요할 때 지연 로드한다. 목록의 버튼만으로 구간 API를 항목별 조회하지 않는다.
